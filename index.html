📤 怎么发给别人用（手机 / 电脑）
这个文件是单独的、不联网也能用的网页，整个发给对方就行，对方不用装任何东西。
  1. 电脑（最省事）：双击文件，用浏览器打开即可。也可以直接发给对方，对方双击就能用。
  2. 安卓手机：微信/QQ 收到文件 → 点右上角 ··· → 用其他应用打开 → 选「浏览器」。打开后可以「添加到主屏幕」，以后像 App 一样点开就用。
  3. iPhone：微信里点开文件 → 分享 → 存储到文件。注意「文件」App 里的预览有时只显示代码或不执行脚本，点不动就属于这种情况，不是文件坏了，改用下面第 4 条发链接最稳。
  4. 想让对方在微信里点一下就能用（推荐）：把它变成一个网址。文件不依赖任何后台服务，传到任意免费静态托管即可：GitHub Pages、Netlify Drop、Cloudflare Pages，或你自己的服务器 / 对象存储。拿到链接发出去，手机电脑点开就是完整功能。整个文件只有 约 45KB，上传没有任何门槛。
  5. 临时分享给同一个 WiFi 下的人：在文件所在文件夹执行 python3 -m http.server 8000，再让对方访问 http://你的电脑IP:8000/凑单计算器.html（IP 在「系统设置 → 网络」里看）。只在自己电脑开着时才有效。
小提示：填过的内容只存在使用者自己的手机/电脑里，不会上传到任何地方；换设备不会同步。
